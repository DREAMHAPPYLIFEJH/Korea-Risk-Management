System Overview / 시스템 개요

This system is designed as a deterministic investment decision engine, not a conventional analytics dashboard.

1.1  Design Intent / 설계 의도

KOSPI market data is widely available, but structured risk interpretation and the translation of that interpretation into investment action are not. This system exists to close that gap — converting raw indicators into an explainable, deterministic risk signal and a directly actionable strategy, without requiring manual interpretation at any stage.

Design PrincipleRationale
Deterministic, rules-basedInvestment decisions require traceable, reproducible reasoning; no probabilistic inference
Independent risk modelsIsolates failure domains; each model is auditable and replaceable in isolation
Layered, market-agnostic architectureOnly data sources and thresholds vary per market; the pipeline core is fully reusable
Score-to-strategy direct mappingEliminates interpretive gaps between risk measurement and portfolio action

1.2  Core Pipeline / 핵심 파이프라인

End-to-End Pipeline 
Raw Data  →  Indicators  →  Risk Levels  →  Composite Score  →  Strategy  →  Insights

1.3  Key Design Decisions / 주요 설계 결정

DecisionChoiceRationale
Risk evaluationIndependent per modelPrevents cross-contamination; each model is auditable
Score aggregationWeighted sum with dynamic weightsMarket-regime-aware; deterministic
Strategy mappingScore-band lookup tableZero ambiguity; no model inference
Insight generationRule-match over condition tableReproducible; same inputs always produce same output
Fallback on data failureHold last valid value + flagPrevents cascading null propagation

1.4  System Constraints / 시스템 제약

Macro Risk Model / 매크로 리스크 모델

Architectural Distinction Unlike the four threshold-based models in Section 4, the Macro Risk Model is architecturally distinct: it is the only model that applies a compound internal pipeline — combining level assessment, event detection, and composite scenario evaluation — where each stage refines or overrides the output of the previous.

Evaluates macroeconomic pressure through three sequential stages — weight 20% in the composite score. Stage 2 adjusts the Stage 1 base grade; Stage 3 overrides both.

[Stage 1: Level]  →  [Stage 2: Events]  →  [Stage 3: Scenarios]
   Base grade          ±1 per event           Critical override

6.3  Composite Score Formula / 복합 점수 공식

Score Formula
Score = (Market × W₁) + (Volatility × W₂) + (Macro × W₃) + (Liquidity × W₄) + (Downside × W₅) Range: 1.0 (all Low) – 4.0 (all Critical) Boundary: boundary values map to the higher band (e.g., 2.5 → Danger) Override: ≥ 2 models Critical + score > 2.5 → immediate defensive transition

Error Handling & Robustness / 오류 처리 및 견고성

Resilience Policy Layered fallback at every pipeline stage. Degraded operation is always preferred over a full halt. Failures are contained to the layer of origin.

11.1  Data Layer / 데이터 레이어

FailureHandling
API unavailableRetry × 3 (exponential backoff); fall back to last valid value; data_stale = true
Holiday / missing dateForward fill from prior trading day
Outlier value (> ±3σ)Cap at ±3σ boundary; log for review
Partial fields nullCalculate from available fields; mark affected models as degraded

11.2  Indicator & Model Layer / 지표 및 모델 레이어

FailureHandling
Insufficient history for MA₁₂₀Skip MA₁₂₀ alignment check; grade from remaining indicators
VaR sample < 252 daysUse available history; append low_sample warning to insight
ADX not computableTreat ADX condition as neutral; exclude from grade logic
Model returns null gradeSubstitute Medium (2) as safe default; log failure

11.3  Scoring & Delivery Layer / 점수화 및 전달 레이어

FailureHandling
All 5 models degradedHalt pipeline; display maintenance notice on dashboard
Composite score out of [1.0, 4.0]Clamp to range; log anomaly
Email delivery failureRetry × 2; alert remains visible on dashboard
Push notification failureFall back to dashboard popup only

Conclusion / 결론

13.1  Design Summary / 설계 요약

System Purpose The system addresses three structural gaps in KOSPI market risk analysis: the invisibility of structured risk, the fragmentation of risk signals across data domains, and the absence of a direct path from analysis to portfolio action. The 7-layer pipeline resolves these by decomposing risk into five independently auditable models, aggregating them into a single interpretable score, and mapping that score deterministically to investment strategy and natural-language insight.

13.2  Core Properties / 핵심 속성

PropertyImplementation
ExplainabilityEvery output — grade, score, strategy, insight — traces to specific indicator values and documented rules
DeterminismIdentical inputs always produce identical grades, scores, and strategies; no stochastic elements
ResilienceLayered fallback at each pipeline stage; degraded operation is preferred over full halt
ExtensibilityLayers 2–7 contain no market-specific logic; only Layer 1 parameters change per deployment

13.3  Evolution Path / 발전 경로

Phases 2 through 5 extend the system's market coverage, data frequency, and output richness without modifying the base 7-layer architecture. The independent risk model structure, deterministic scoring engine, and rule-based output pipeline remain unchanged across all planned phases. The system is designed to absorb scope growth at the boundary of Layer 1 and indicator thresholds, leaving the core pipeline stable.
